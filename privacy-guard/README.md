# Privacy Guard

Работа с видео, аудиофайлами, вебкамерами и RTSP-потоками.

## Запуск

Нужен Node.js 22.12 или новее. В папке проекта:

```powershell
npm ci
npm run dev
```

Адрес: http://127.0.0.1:4173

Для собранной версии:

```powershell
npm run build
npm start
```

## Возможности

- Видео: ручное скрытие областей и сохранение WebM с исходным звуком.
- Аудио: выделение участков для заглушения и сохранение WAV.
- Прямой эфир: вебкамера, показ экрана или RTSP-поток, ручное скрытие областей и запись WebM. Звук экрана сохраняется, если браузер передаёт аудиодорожку.
- Библиотека: просмотр файлов, поиск, избранное, переименование и скачивание.
- Белый список: люди с фотографиями, автомобили с номерами и экспорт CSV.
- Настройки: тема, язык и параметры категорий.

Автоматическое распознавание пока не подключено.

## RTSP

В разделе «Прямой эфир» выберите «Поток по ссылке (RTSP)» и укажите полный адрес потока из настроек камеры или приложения на телефоне, например `rtsp://192.168.0.100:554/stream`.

После подключения доступны кнопки «Начать запись» и «Завершить запись». Готовая запись сохраняется в библиотеку. FFmpeg устанавливается вместе с зависимостями.

Для показа своего экрана выберите «Мой экран» → «Выбрать экран». В диалоге браузера укажите окно, вкладку или экран. Показ работает локально: другие пользователи не получают ссылку на ваш экран. Чужую трансляцию можно открыть по прямой RTSP-ссылке.

## Данные

Файлы библиотеки, фотографии и белый список хранятся в `data/`. Эта папка исключена из Git.
